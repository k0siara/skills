# Credits

Inspired by [Matt Pocock's `to-tickets` skill](https://github.com/mattpocock/skills/tree/main/skills/engineering/to-tickets): tracer-bullet vertical slices sized for one fresh context window, blocking edges instead of a phase document, prefactoring first, expand–contract for wide refactors, quizzing the user on the breakdown before publishing and publishing blockers first. The ticket's behavioural wording follows his [`triage` agent brief](https://github.com/mattpocock/skills/tree/main/skills/engineering/triage).

Some ideas come from Cursor's [pstack](https://github.com/cursor/plugins/tree/main/pstack) plugin (MIT): one PR as one change with its own evidence, a way to verify named in every unit of work, and checking the plan against a fixed list before handing it over.

This skill uses an independently written workflow and template; neither upstream is a runtime dependency.

# Credits

Some ideas come from Cursor's [pstack](https://github.com/cursor/plugins/tree/main/pstack) plugin (MIT): a reviewer or verifier who did not write the code, `INCONCLUSIVE` as a verdict that never counts as a pass, project verification skills that drive the real app, and reproducing a defect before fixing it. This skill uses an independently written workflow; pstack is not a runtime dependency.
